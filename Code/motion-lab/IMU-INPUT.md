# Motion Lab IMU 接口

## 离线记录

在姿态面板下选择 **导入 IMU**，打开经过融合的本地 JSON。绑定按当前 BA 记录 ID 验证，附件在本次应用会话中可用于回放与复盘。内置 ST09 和 ST02 没有附带 IMU 四元数。演示姿态由按钮显式启用，面板标为合成示例。

```json
{
  "schema": "motion-lab-imu/v1",
  "trialId": "ST09-BA-paretic-01",
  "side": "right",
  "samples": [
    {"t": -0.050, "q": {"trunk":[1,0,0,0], "upperArm":[1,0,0,0], "forearm":[0.70710678,0,-0.70710678,0]}},
    {"t": 0.000, "q": {"trunk":[1,0,0,0], "upperArm":[1,0,0,0], "forearm":[0.70710678,0,-0.70710678,0]}}
  ]
}
```

示例内容用于说明文件结构。真实采集时应导出各传感器的单位四元数，按 `[w,x,y,z]` 排列，从传感器系旋转到 Z 向上、重力已对齐的世界系。时间 `t` 用秒，以 EMG 的 Events.Start 为零点，静息可为负；样本严格按时间递增。省略某个段或填 `null` 表示该帧没有该段的数据。

可选 `calibration.neutral` 为静息参考的三段实测四元数，`calibration.offsets` 为三个已知的 `q_off`（右乘到传感器四元数）。无中立参考时，使用记录首个静息窗口中各段的平均四元数。无需在前端做融合或漂移修正。

## 在线界面演示

选择 **在线检测 → 连接设备 → 选择模拟设备**。演示用同一会话切换双路预览、标定、检测、断线续接和试次摘要。设备详情下的 **模拟控制** 提供单路缺失和断线场景。

实时页面以样例波形和示意姿态演示操作。导出按钮生成演示摘要，试次数据在当前应用会话内展示。已保存的旧记录和录像可以通过 **试次复盘** 打开。

## 验收与调参

- 解压源码后使用 Node.js 24，运行 `npm ci`、`npm test`、`npm run build`。`npm run desktop` 从构建结果启动 Electron。
- `src/pose/poseConfig.ts` 集中定义时间偏移、段长、缓冲区、丢包等待、激活平滑和刷新速率。
- `src/pose/poseMath.ts` 定义静息几何和唯一的 Z-up 到 Y-up 转换。静息自检检查读数及窗口内波动。绝对姿态的标定精度还依赖设备安装与已知参考姿势。
- `src/pose-layout.css` 定义两列宽度和窄窗口切换阈值。
