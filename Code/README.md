# BA 抓球动作表示学习 V1

接手实验请先读 [EXPERIMENT.md](EXPERIMENT.md)。其中记录版本、教师对照命令和结果验收口径。

目标是检验两件事。首先，结合表面肌电和完整光学运动学的教师，能否重建留出受试者的遮挡片段。其次，只使用原型可观测特征的学生，能否通过蒸馏保留更多有用的动作信息。健康和卒中试验都进入自监督训练，组别信息用于划分折和训练后的探索性分析。

## 训练结构

| 环节 | 输入 | 模型与目标 |
|---|---|---|
| 教师预训练 | 6 路 sEMG 包络和 16 路光学运动学 O | 两个分支分别用核大小为 5 的一维卷积和一层 BiLSTM。每方向宽度为 16，逐帧拼接后投影到 24 维。分别遮挡两种模态各约 30% 的连续时间块，用两个线性头重建被遮挡的数据。 |
| 学生蒸馏 | 同次试验的 6 路 sEMG 包络和 7 路公共运动学 K_opt | 两个分支采用相同的结构，每方向宽度为 8，逐帧融合成 12 维。冻结教师，用未遮挡信号计算目标特征。学生的线性投影将 12 维映射到 24 维，按有效时间点与教师特征做均方误差。 |
| 学生对照 | 和蒸馏学生相同 | 使用相同网络、初始权重、掩码序列和训练轮数，仅用遮挡重建训练。 |
| 整次动作表示 | 学生的逐帧 12 维特征 | 将完整动作按相对时间分成三个等长部分，各自做均值池化，拼成 36 维。三个池化区间是时间摘要，无需人工动作阶段标签。 |

教师损失是两种模态遮挡位置的平均标准化 MSE。学生保留同样形式的重建目标，另加 `0.5 × 特征蒸馏 MSE`。重建项提供直接的信号约束，也让有无蒸馏的学生可以公平比较。预训练时两分支分别接收遮挡标记。批处理使用打包序列，填充位置不会进入双向循环或损失。

## 数据与验证

- 使用官方 BA Start/End 覆盖整次抓球，按名映射 BB、TB、AD、MD、FCR、ECR。149 次试验来自 20 人，包括 50 次健康优势侧、50 次卒中患侧和 49 次非患侧。
- 光学与肌电使用采样率和名义共同起点对齐到 50 Hz，保留各次动作实际长短。肌电做 20–450 Hz 双向带通和 50 ms 居中 RMS，再做抗混叠低通。光学标记轨迹只填补有双端观测的短缺失，随后做 6 Hz 双向低通。完整动作、双向滤波和 BiLSTM 对应离线分析。
- K_opt 包含胸廓坐标中的上臂方向 3 分量、前臂方向 3 分量及肘屈曲角。O 另包含肩相对腕位置、速度及手部方向，共 16 个特征。原型端要将三枚 IMU 的定向结果校准至相同的胸廓和肢段坐标系，再用同步光学参考核对两种来源的误差。
- 按人做 5 折分层划分。同一人的双侧和重复动作都在同一折。信号标准化和线性读出均只在当前训练折拟合。重建误差先按次计算，再在受试者层面取宏平均。
- 教师重建和同掩码的线性插值对照。学生比较有无蒸馏时对原信号的重建、对教师特征的线性拟合，以及由冻结表示预测腕路径长度等指标的误差。把时长基线、简单信号统计量和训练中位数纳入相应读出任务。外侧变化和腕路径是由光学计算的动作指标，用于检查表示中保留的信息。
- 健康优势侧与卒中患侧的组别线性探针按人汇总，非患侧仍参加自监督训练与动作指标评估。年龄、动作时长、受累侧与个体测量条件都可能影响组别分离。结果适合描述本数据的探索现象。各折网络独立训练，跨折嵌入的坐标轴不共享，比较嵌入的散点图应在单折内绘制。

## 复现

用 Python 3.12。在 `Code` 目录执行。默认读取仓库中的 `../emg_dataset`，MATLAB 字符串由 `ba_data.py` 解析。数据放在其他位置时可用 `--data` 指定。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python train_ba.py --epochs 4 --folds 5 --output runs/ba_v1_repeat
```

默认模式 `full` 训练教师、无蒸馏学生和蒸馏学生，每个模型默认 24 轮。`--teacher-epochs` 可单独设置教师轮数。两种仅训练教师的模式及其比较规则见 [实验记录](EXPERIMENT.md)。输出目录需尚未存在，以保留独立运行记录。

| 输出 | 内容 |
|---|---|
| `summary.csv` | 重建、特征对齐和动作指标探针的汇总 |
| `trial_metrics.csv`、`probe_predictions.csv` | 留出预测和逐次误差 |
| `student_embeddings.csv` | `full` 模式下留出试验的 36 维学生表示与折编号 |
| `fold_*.pt` | 每折的教师、学生、投影层、标准化参数和数据划分 |
| `config.json`、`splits.json` | 参数、通道与受试者划分 |

## 首轮结果

`runs/ba_v1_pilot` 包含 5 折、每个模型 4 轮的短跑。20 名受试者均有独立留出预测，每次试验只在所属测试折评估。重建和连续指标报告受试者宏平均。

| 指标 | 第一项 | 对照 |
|---|---:|---:|
| 教师肌电重建 MAE（标准化单位） | 0.697 | 插值 0.543 |
| 教师光学重建 MAE（标准化单位） | 0.772 | 插值 0.560 |
| 学生到教师的线性对齐 MSE | 蒸馏 0.099 | 无蒸馏 0.103 |
| 腕路径长度 MAE | 蒸馏 7.81 cm | 无蒸馏 8.39 cm；仅用时长 6.59 cm |
| 上臂外移变化 MAE | 蒸馏 4.59° | 无蒸馏 4.40°；简单信号统计量 2.75° |
| 健康优势侧与卒中患侧探针平衡准确率 | 蒸馏学生 55% | 无蒸馏学生 50%；仅用时长 70% |

蒸馏让学生的表示略接近教师，但各动作指标的变化方向不同。腕路径的误差在 11/20 人上低于无蒸馏对照。四轮短跑验证了实现和数据链路，目前尚未建立相对简单基线的稳定优势。

下一轮优先验证教师。固定现有受试者划分，预先定义掩码长度和训练轮数，用相同掩码比较线性插值、单模态重建与双模态重建。用腕路径及上臂外移检查冻结表示的价值，保留时长和简单统计量对照。公共 BA 实验完成后，再用同步光学与三枚 IMU 的少量试验核对 K_opt 和 K_IMU 的一致性。
