# BA 全通道动作模式探索研究方案

版本：2026-11-24。路线 A，步骤 1–3。交付语言：中文。

**A、B 对比入口：**[双路线 proposal](PROPOSAL.md)；[路线 B 方法与实测结果](route_b/README.md)。本 README 详细记录 A，`route_b/` 独立保存 B 的代码、结果和补充 Word 报告。

本项目从真实 BA 抓球记录中探索可重复的运动与肌电表现，为后续独立复核和模式识别选择研究目标。本轮使用全部 **12 路肌电**，完成数据审计、离线预处理、阶段估计、连续特征分析和参数敏感性检查。**没有生成正常／异常训练标签，没有训练分类器，也没有做通道筛选。**

## 本轮实测结论

20 人、30 条 BA 侧别记录、149 次动作全部进入接近球阶段分析。健康优势侧 50 次、卒中患侧 50 次、非患侧 49 次。统计先在每名参与者的同侧重复动作中取中位数，再作组间描述，不能把 149 次动作当成 149 个独立受试者。

1. **阶段耗时差异值得继续调查。**接近球时长的组中位数为健康 0.516 秒、患侧 0.736 秒；搬运中段为 0.448 与 0.680 秒；接近结束至搬运中段间隔为 0.492 与 0.824 秒。间隔包括抓取、准备及搬运早期，不能命名为纯抓握时间或病理性卡顿。
2. **上臂外侧姿态差异存在于部分患者。**患侧 ST02、ST03、ST06、ST07 的个人外侧分量 P95 中位数高于本样本所有健康参与者的对应中位数。这只是样本内排序，不是异常阈值。ST07 动作中的外侧分量增量接近零，提示较高起始外偏不能等同于动态绕行。
3. **BB/TB 重叠有探索价值，但依赖处理方法。**健康、患侧个人中位数的组中位数为 0.546、0.644；9/10 患者患侧高于本人非患侧。扣除静息 RMS 背景后的对应值约为 0.224、0.407，绝对值明显改变。不能据此诊断代偿或肌张力异常。
4. **没有发现“患侧普遍中途停顿”的证据。**默认规则在接近球阶段未检出持续低速区间，在搬运中段仅在 ST03 非患侧第 1 次检出 0.504 秒候选区间。阶段端点、末端修正及操作间隔不属于这一窄定义，零检出不等于整次动作完全平滑。

上述均为描述性探索。主要组差的受试者 bootstrap 区间跨零，不能据此声称稳定的总体差异或已验证的诊断指标。

## 研究问题与边界

研究问题：BA 不同阶段是否存在跨患者重复出现的时长增加、外侧姿态改变和肌肉活动重叠变化？这些表现是否在同一人的重复动作中稳定，并对合理处理参数不敏感？

以健康优势侧作为小样本参考，以患者非患侧作为配对补充，不将非患侧等同于健康。全量公共数据用于发现与可行性检查，当前没有独立测试集；未来需要冻结定义并使用新患者，或在每个外层训练折内重新发现模式。当前数据中没有明确出发提示，因此不计算提示反应延迟。没有独立康复师标注，不能把几何代理和肌电重叠直接命名为临床代偿。

## 原始数据和审计

原始目录：`F:/dataset/dataset`，只读。`F:/dataset/__MACOSX` 不参与分析。20 个 MAT 文件包含六类任务的 180 个侧别任务记录，共 897 个原始 Start/End 重复事件。本轮仅分析 BA。

MATLAB 原生导出用于解码 string 对象。Python 不按通道序号猜测肌肉名称。原始文件 SHA256、大小保存在 `results/source_manifest.json`，导出的字段名保存在 `results/schema.json`。

发现的源数据差异：

- 坐标数值按毫米处理再转换为米；30 条 BA 的肩宽量级支持此解释。论文表格的单位写为 m，而作者示例脚本标作 mm，需在发表前与作者确认。
- BA 文件实际含 19 行关节角，不是论文表格的 20 行。
- 本地 ST07 非患侧有 4 次 BA，ST08 两侧均有 5 次；以实际 Events 为准。
- 运动学与 EMG 总长度差约 -0.024 至 +0.108 秒。采用采样率和共同起点对齐，不把两条信号强制拉伸至同长。长度差不证明存在同等同步偏移，另作 ±100 ms 敏感性分析。
- 健康与卒中年龄不匹配，使用年龄区间中点计算的中位数为 55.0 和 79.5 岁。患侧 L_CA 仅覆盖 3–5 级，不能泛化到严重无自主运动患者。

## 可复现处理方法

### 数据与信号

运动学 125 Hz、EMG 1000 Hz。MATLAB 1-based inclusive Start/End 转换为 Python 0-based，完整保留原始事件。运动学只填补两端有效且不超过 80 ms 的短缺失；较长缺失不填。额外使用 4 阶 6 Hz 双向低通，速度由滤波后腕部位置求导。腕点定义为尺骨与桡骨茎突中点。

EMG 使用 4 阶 20–450 Hz 双向带通、50 ms 居中 RMS；不代表实时因果处理。各通道以同一条侧别 BA 记录全部有效动作样本的 RMS P95 作参考，P99 作敏感性对照；这不是 MVC，也不能解释为肌力百分比。静息参考是各原始 Start 前 0.50 至 0.05 秒的 RMS 中位数，不能保证患者完全放松。

### 阶段估计

接近球：原始 Start 至物体首次持续位移超过 10 mm 之前，寻找腕点到初始物体位置的最小距离；首次到达该最小值加 20 mm 的时刻作为接近结束。接近起点由该段腕速超过局部峰值 5% 且持续 80 ms 估计。该定义有意避开抓取，但可能截掉末端修正。

搬运中段：物体相对初始位置移动超过 150 mm 后，第一次持续至少 300 ms、速度低于 30 mm/s 的区间作为暂定到位平台。以初始位置至该平台的方向投影，取进度 10% 至 90%。采用第一次平台，避免试次末尾标记点移动把返回动作纳入搬运。

另记录接近结束至搬运中段的操作间隔，以及搬运中段结束至原始 End 的剩余时段。后者包含减速、放置、释放和返回，不能解读为纯保持时长。分期均为算法估计，没有人工真值。

### 连续指标与候选区间

- 低速区间：阶段中间 80% 内，腕速低于 `max(0.005 m/s, 0.1 × 阶段峰速)`，连续至少 0.25 秒。记录发生区间，不产生正常／异常标签。
- 速度峰：突出度 ≥ 阶段峰速 15%，间隔 ≥150 ms。峰数可能漏掉边界和末端修正，不作为独立平滑性结论。
- 路径比：腕点实际路径长度／阶段首末点直线距离。
- 上臂外侧分量：上臂单位向量与双肩连线朝患肢外侧的单位向量点积取 arcsin。记录阶段 P95 及相对起点变化。它是几何代理，不是完整的解剖肩外展角，也不直接证明绕行。
- 活动重叠：归一化包络 x、y 的 `2 × sum(min(x,y)) / sum(x+y)`。这是本项目指定公式，不与不同归一化或公式的文献数值混用。
- 背景敏感性：先扣除各通道静息 RMS 并截断为零，再用相应参考尺度重算。该操作检验背景影响，不是已经验证的去噪真值。

### 统计与敏感性

先对每个人同侧重复取中位数，再比较组中位数、四分位数与个体分布。健康与患侧的中位数差采用 3000 次受试者 bootstrap、随机种子 20261124；这是未经多重性校正的探索区间，不用于选择显著指标。

已运行物体位移 5/10/20 mm、低速比例 5%/10%/15%、持续时间 0.15/0.25/0.40 秒；EMG P95/P99、±100 ms 时间平移、静息背景扣除。尚未覆盖所有阶段定义和滤波参数，不声称完全稳健。

在本目录打开 PowerShell，已导出数据可直接运行：

```powershell
python src/run_analysis.py
python src/explore.py
python src/quality_checks.py
python src/make_figures.py
python -m unittest discover -s tests -v
```

```powershell

```

## 下一阶段方案

优先复核阶段边界、操作间隔、外侧初始姿态与动态变化，以及患侧／非患侧 BB/TB 的配对差异。先由独立评价者判定这些信号表现的含义，再决定是否生成弱标签。不把本轮样本内极值当成临床阈值。

若继续训练，按每种模式分别定义二分类任务，按受试者分组，在训练折内完成参考估计和模式选择；同一人的双侧与所有任务必须归入同一折。比较规则、简单特征模型、TCN及蒸馏学生。公共数据已用于全量探索，可信的最终检验优先使用新患者。全 12 通道保留到证据支持缩减为止。
