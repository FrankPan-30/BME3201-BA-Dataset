# 路线 B 全通道无监督片段探索

日期：2026-11-24。与 A 使用同一份审计和预处理数据，使用全部 12 路肌电。**群组编号只表示相似片段，不是正常／异常标签；没有训练诊断分类器。**

## 先看结论

原始片段聚类主要找到了动作内部的时序规律。控制阶段位置后，搬运中段出现一个相对较慢、速度波动较大、外侧姿态偏大的组合群组，覆盖 8 名患者，也覆盖 5 名健康参与者。它适合继续复核，但不能叫“卒中特异异常”。接近球阶段的细分群组不够稳定，暂不作为模式库。

重要比较：A 更适合直接解释连续差异；B 能提出组合模式，但当前组合主要仍由运动学驱动，尚未证明全通道肌电带来额外识别价值。完整讨论见 [PROPOSAL](../PROPOSAL.md) 与 [补充报告](docs/B路线探索与AB对比报告.docx)。

## 数据与特征

每次有效动作分别在接近球和物体搬运中段划成前、中、后三个等时长片段。共 894 个片段：每阶段健康＋患侧 300 个，非患侧投影 147 个。主聚类严格为 20 人、每人每阶段 15 段，避免长动作产生更多窗口而支配群组。等相位片段长度不同，保留真实起止时间，不把 600 段当作 600 名独立受试者。

每个片段 30 个特征：12 通道各自的归一化 RMS 均值及波动系数（24 个）；腕速均值及波动、上臂外侧分量、肘角、肘角速度和外侧分量变化速度（6 个）。波动系数分母分别加 0.05（归一化 EMG）和 0.01 m/s（腕速）以限制低幅值放大。全部特征见 segments.csv。

拟合流程为 RobustScaler、截断至 ±4、模态权重、8 维 PCA、KMeans。EMG 块和运动学块分别除以 √24 和 √6，以免单纯由通道数量决定权重。k 在 2–5 中按轮廓系数选择，随机种子 20261124，KMeans 30 次初始化。选择 k 没有使用健康／卒中身份。

## 两个探索版本

### B1 原始片段

分别对接近球和搬运聚类，不把两种宏观阶段混在一起。两者均选 k=2；轮廓系数约 0.210、0.246。剔除部分参与者重拟合的 ARI 中位数约 1.000、0.987，看起来非常稳定。

但接近群组 0 中 95.2% 是前段，搬运群组 0 中 84.2% 是后段。群组与相位位置的 NMI 为 0.643、0.512，与人群身份的 NMI 仅 0.001、0.003。这些群组主要反映正常时序结构，不能命名为两个异常类别。

### B2 控制阶段位置

在每个相对位置分别扣除全部主发现参与者的特征中位数，再重复同样流程。这里不使用健康身份作扣除参考；每次参与者重抽样都会重新估计位置中位数、归一化、PCA 和群组。

- 接近球选 k=5，轮廓系数 0.171，ARI 中位数 0.511，四分位范围 0.417–0.700；群组与身份 NMI 升至 0.418。一个群组 41.7% 片段来自同一人，提示个体习惯或信号条件可能主导。暂不接受为稳定共性。
- 搬运中段选 k=2，轮廓系数 0.231，ARI 中位数 0.819，四分位范围 0.613–0.881。并非每次重拟合都稳定，最低 ARI 约 0.380，故仍是候选。

搬运群组 1 有 94 个主发现片段，其中 74 个来自患者（78.7%），覆盖 8 名患者和 5 名健康参与者，单一参与者最大贡献 14.9%。8 名患者均在至少 3 次动作中出现该群组片段。群组 0 与 1 的片段腕速中位数分别为 0.838 和 0.470 m/s；外侧分量为 39.46° 和 42.75°。这些数字是片段级群组描述，不是组间临床推断。

## 这是不是发现了肌肉代偿

目前不能这样解释。搬运群组 1 同时表现出较高的桡侧腕伸肌归一化活动和略高的 BB 活动，但仅运动学聚类与联合聚类的 ARI 为 0.881，仅 EMG 为 0.241。说明此版本的群组主要由运动学决定；不能把肌电相伴变化当作机制或必要信息。

HS09 的 15 段中有 14 段进入群组 1。这个反例说明该群组不具卒中特异性，年龄、速度、姿势等因素仍需控制。

## 稳定性不是准确率

每阶段做 30 次随机保留 16/20 名主发现参与者的重拟合，再对全体片段投影，与全量参考分组计算 ARI。它测量分组对样本组成的敏感性，**不是独立测试准确率**。原始参与者在多次重抽样中重叠，片段也非独立；不据此计算诊断敏感度或特异度。

非患侧只投影，不参与参考、PCA 或 KMeans 拟合。其结果供配对探索，不是外部独立验证。所有病例均来自已查看的公共数据。

## 代码与复现

先完成根目录 A 的脚本，再在根目录执行：

```powershell
python route_b/src/discover.py
python route_b/src/control_phase.py
python route_b/src/summarize.py
```

`discover.py` 提取全通道片段并执行 B1；`control_phase.py` 执行 B2；`summarize.py` 生成图和受试者覆盖表，验证保存的中心、尺度、PCA 与群组中心可精确重建所有群组归属。`build_b_report.py` 生成补充 Word。

`results/segment_membership.csv` 和 `phase_control_membership.csv` 的 cluster_id 仅为内部群组编号。编号在不同版本间不对应，不能用于临床训练标签。`fit_role` 区分主发现数据和非患侧投影。

结果来源与原数据引用见根 README。后续优先做独立动作复核和速度／年龄匹配，只有证据支持时才考虑正式打标及训练。
